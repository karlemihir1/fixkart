# FixKart® — Repair-Commerce Marketplace

> **Don't Replace It. Fix It.**
> India's first decentralized repair-commerce marketplace connecting broken home appliances, consumer tech, and commuter two-wheelers to verified OEM/compatible spare parts and top 1% local master technicians with an instant 90-day digital guarantee.

---

## ⚡ Core Features

- **5-Step Optical AI Diagnostic Wizard**: Device selection → Dynamic symptom decision tree → Brand/Model selector → Optical computer-vision scanner simulation → Root cause & Triple-Tier Part Matrix.
- **Triple-Tier Spare Parts Recommendation**: Side-by-side comparison of **OEM Genuine**, **Certified Compatible**, and **Value Economy** spare parts.
- **Direct Doorstep Mechanic Call (₹199)**: 1-click option for users who cannot diagnose their appliance—dispatches a senior master technician with testing tools to inspect on-site and fix everything.
- **"Will This Fit My Product?" Compatibility Tester**: Real-time compatibility verification for thousands of appliance models.
- **Verified Technician Discovery**: Top 1% vetted master technicians (98.4% first-time-fix rates, express 35-min arrival ETAs, slot picker).
- **Digital Repair Passport™**: Tamper-proof certificate with unique Passport ID, before/after photo evidence, technician license hash, and 90-day warranty countdown.
- **Multi-Role Ecosystem**: Instant role switcher to test **Customer**, **Technician (Raj Kumar)**, **Supplier (Apex Spares)**, and **Admin Ops Control Center**.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Custom Kinetic Typography (`Oswald`, `Anton`, `Epilogue`, `Plus Jakarta Sans`, `Space Grotesk`)
- **Icons**: Lucide React + Custom SVGs
- **State Management**: Reactive React Context with multi-role cross-portal sync

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/fixkart-app.git
cd fixkart-app
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
